# Tkinter Tic-Tac-Toe
## Overview
A Python desktop game with local two-player and computer-opponent modes. This is a learning project in event-driven programming and game-state handling.

## Key Features
- A 3×3 button board, symbol choice, win/draw detection, and replay prompt.
- A rule-based computer opponent: try a winning move, block a loss, then prefer the center/corners before other available moves.
- No machine learning or minimax implementation is claimed.

## Technologies and Structure
Python 3, Tkinter, random, and copy. `project2.py` contains the game; `project2.exe` is an existing Windows binary whose build provenance is not documented.

## Installation and Usage
Use a graphical desktop and Python with Tkinter:
```sh
python project2.py
```
Choose the mode and symbol, select Yes, and start the game. No third-party Python packages or credentials are needed. The GUI was not executed during this documentation update.
